## Upload steps

1. Create a new public repository named `flight-delay-analysis-dashboard`.
2. Upload the contents of this folder, not the enclosing folder itself.
3. Confirm that the four screenshots render inside the README.
4. Set the repository description shown above.
5. Add the suggested topics.
6. Pin the repository on your GitHub profile.

## CV entry

## Final checks before publishing

- Open the PBIX once from the repository folder.
- Confirm that no local or confidential data is included.
- Keep all screenshots unfiltered.
- Check that every README image path uses lowercase filenames exactly as stored.
- Do not upload the backup PBIX.
